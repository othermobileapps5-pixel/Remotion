# Video skill'lar

Bu repoda ishlaganda Claude shu skill'larni o'zi ishlatadi.

| Skill | Nima qiladi | Manba (litsenziya) |
|---|---|---|
| `cartoon-3d-short` | 55–70 s multfilm-hikoya: 3D shaharda 2D qahramonlar (three.js + Remotion) | mromidev/claude-animated-shorts (MIT) |
| `shorts` | Uzun videodan (YouTube, podkast) eng qiziq qismlarni topib, subtitrli Shorts/Reels yasaydi | AgriciDaniel/claude-shorts (MIT) |
| `ffmpeg-skill` | Kesish, ulash, 9:16, pauzani olib tashlash, ovoz balandligi, eksport | kajisho5/ffmpeg-skill (MIT) |
| `ghost-editor` | Telefonda o'zingizni gapirib yozgan xom videodan tayyor Reels: eng yaxshi dubl, pauza, subtitr, effektlar | kurbaitaev/ghost-editor (MIT) |
| `hf-*` (9 ta) | HyperFrames rasmiy skill'lari: HTML'dan video, CLI, media, slideshow, Remotion→HyperFrames, videoni qayta yasash | heygen-com/hyperframes (Apache-2.0) |
| `openmontage` | Mavzudan to'liq video: tadqiqot, ssenariy, stok/AI materiallar, montaj — kerak bo'lganda klonlanadi | calesthio/OpenMontage (AGPL-3.0) |

Eslatma: `ghost-editor` ning katta media fayllari (docs/media) qo'shilmagan; ovoz va musiqa kutubxonasi `scripts/library_restore.py` bilan yuklanadi.
