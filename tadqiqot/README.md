# Tadqiqot

«Tadqiqot» workflow'i (qo'lda) Agent Reach bilan internetdan o'qiydi va natijani **`tadqiqot` branch'iga** `tadqiqot/<nom>.json` qilib yozadi.

| Buyruq | Misol |
|---|---|
| `read` | YouTube video yoki sahifa havolasi — matn, subtitr |
| `youtube-search` | "Hollywood sign history" |
| `web-search` | "Hollywoodland sign 1923" |
| `github-search` | "remotion three.js" |
| `channels` | qaysi kanallar va buyruqlar borligini ko'rsatadi |

Faqat o'qish. Login talab qiladigan kanallar (Twitter, Reddit, Xiaohongshu) yoqilmagan.
Manba: github.com/Panniantong/Agent-Reach (MIT), v1.6.1 — yangi versiyaga faqat egasi rozi bo'lsa o'tiladi.
